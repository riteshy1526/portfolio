# 🚀 Personal Portfolio Website

A modern and responsive portfolio website built to showcase my skills, projects, education, certifications, and professional experience. The website features a futuristic UI design, smooth animations, and a mobile-friendly layout to provide an engaging user experience.

## ✨ Features

* Fully Responsive Design
* Modern Dark-Themed UI
* Interactive Navigation
* Animated Hero Section
* Skills Showcase
* Projects Portfolio
* Education & Certifications Section
* Contact Information & Social Links
* Smooth Scrolling Effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎨 Design Highlights

* Custom CSS Variables
* Glassmorphism Elements
* Gradient Effects
* Animated Skill Bars
* Responsive Grid Layouts
* Interactive Cards and Hover Effects
* Mobile-Friendly User Interface
